# Grievance Redressal Mechanism & Helpdesk Escalation Matrix
ST Seva Portal • Ministry of Tribal Affairs (MoTA)

## 1. Multi-Channel Grievance Submission
ST Scholars can register grievances through any of the following avenues:
1. **Online Portal Grievance Module**: Submit ticket under "Lodge Grievance" on the ST Seva Portal with document upload.
2. **WhatsApp Grievance Desk**: Chat with the official ST Seva WhatsApp bot (+91-98765-43210) using command `NEW <CATEGORY> <DETAILS>`.
3. **National Scholarship Portal (NSP) Grievance**: Select "Tribal Affairs" on CPGRAMS / NSP Grievance portal (`scholarships.gov.in/grievance`).
4. **Toll-Free National Helpline**: Call **1800-11-7777** (MoTA) or **0120-6619540** (NSP Helpdesk).

## 2. Escalation Hierarchy & Resolution SLA

| Escalation Level | Authority Designated | Typical SLA | Focus Area |
| :--- | :--- | :--- | :--- |
| **Tier 1 (L1)** | Institute Nodal Officer (INO) / Helpdesk Agent | 3 Working Days | Attendance verification, institute bonafide issues, fee breakdown errors |
| **Tier 2 (L2)** | District Welfare Officer (DWO) | 7 Working Days | Caste certificate validation, income scrutiny, defect re-submission approvals |
| **Tier 3 (L3)** | State Nodal Officer (SNO), Tribal Welfare Dept | 15 Working Days | State quota releases, sanction order delays, fund re-trigger |
| **Tier 4 (L4)** | Joint Secretary / Director, Ministry of Tribal Affairs (MoTA) | 21 Working Days | Policy appeals, systemic PFMS gateway discrepancies, NFST / Top Class escalations |

## 3. Mandatory Information for Grievance Registration
- Permanent Application ID / OTR Number.
- Candidate Full Name & Aadhaar Number (Last 4 digits).
- Grievance Category: "Payment Delay", "Rejection Discrepancy", "Verification Stuck", "Bank IFSC / NPCI Failure", or "Institute Non-Cooperation".
- Detailed summary with timestamped screenshot or defect notice copy.
